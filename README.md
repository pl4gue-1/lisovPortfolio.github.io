# Портфолио — Константин Лисов

Статичный сайт-портфолио: 3D, VFX, цифровая одежда, постобработка.
Только десктоп, тёмная тема, фиксированные кадила по краям, ленты работ.

## Как посмотреть

Откройте `index.html` двойным кликом — сайт работает без сборки и сервера.

Шрифт Cinzel подгружается с Google Fonts, поэтому для точного вида нужен интернет.
Альтернатива — локальный сервер:

```powershell
python -m http.server 8000
# затем http://localhost:8000
```

## Структура

```
index.html          разметка страницы
css/style.css       все стили, палитра и шрифты — в :root
js/config.js        контент: контакты, работы, кейсы
js/i18n.js          тексты RU / EN, включая подписи схемы процесса
js/main.js          ленты, лайтбокс, кадила, переключатель языка
Assets/             исходные kadilo*.png
Assets/web/         обрезанные версии для сайта (используются страницей)
tools/trim_assets.py подготовка ассетов
```

## Как добавить работу

1. Положите файл в `Assets/works/` (например, `Assets/works/modeling/01.jpg`).
2. Откройте `js/config.js` и добавьте запись в нужную секцию:

```js
works: {
  modeling: [
    { img: "Assets/works/modeling/01.jpg", ru: "Безликий", en: "Faceless" }
  ],
  // garments, vfx, post — так же
}
```

Название появится подписью на карточке, а лента сама выстроится и подстроит скорость.
Пока массив пуст — рисуются 8 карточек-заглушек.

Рекомендации: JPG/WebP, длинная сторона 1600–2000 px, GIF до 1,5 МБ.
Для гифок лучше делать постер (первый кадр) и подгружать лениво — сейчас `loading="lazy"` уже стоит.

Кейсы (`cases`) добавляются так же:

```js
cases: [
  { img: "Assets/works/cases/01.jpg", ru: "Проект", en: "Project", tag: "3D + VFX" }
]
```

## Процесс (схема)

Секция `#workflow` — инлайновый SVG в `index.html`: девять этапов от референса
до финала, связи и подписи. Текст этапов переводится через ключи `wf.*` в `js/i18n.js`.
Цвета, рамки и hover — `.wf-*` в `css/style.css`.

Чтобы поменять этап, правьте `<text>` внутри нужного `<g class="wf-node">`;
чтобы добавить/убрать этап — копируйте блок узла и поправьте координаты и связи
(`.wf-link`, стрелки ведут на 8 px раньше края узла).

## Врата и пыль

После каждой скилл-секции стоит полоса тумана: `Sigil1` после 3D, `Sigil2` после одежды,
`Sigil3` после VFX, `Sigil4` после постобработки. Туман — это Canvas 2D: полупрозрачные
клубы дыма, которые медленно поднимаются, слегка меняют размер и рассеиваются
(бесконечный цикл на `requestAnimationFrame`). Расходится позже — когда заголовок
следующей секции уже появился в кадре, — после чего проступает сигил. До раскрытия дым
однородный и сигил не виден; полоса тянется от левого кадила до правого, а не до краёв экрана.

Логика — `initGates` в `js/main.js` (спрайт дыма, частицы, стирание просвета через
`destination-out`), стили — `.gate` / `.gate__sigil` / `.gate__canvas` в `css/style.css`;
прогресс раскрытия живёт в переменной `--p`, центр колонки контента — в `--cx`
(считается в `fitRails`).

Пыль — `<canvas id="ash">`: частицы рождаются у нижней кромки лент работ и падают вниз,
канвас лежит за контентом (z-index 1). Отключается при `prefers-reduced-motion`.

Заменить сигил — положить `sigilN.png` в `Assets/` и пересобрать веб-версии
(`python tools/trim_assets.py`); страница использует `Assets/web/sigilN.png`.

## Просмотр работ

Клик по фото в ленте открывает его по центру экрана без рамки, с подписью внизу.
Подпись берётся из поля `ru` / `en` — того, что идёт сразу после `img` в `js/config.js`.
Закрытие — крестик, клик по фону или Esc.

## Кадила

Страница использует обрезанные PNG из `Assets/web/` — у них убраны прозрачные поля,
поэтому они встают вплотную и не занимают лишнего места.

Если меняете исходные `Assets/kadilo*.png`, пересоберите веб-версии:

```powershell
python tools/trim_assets.py
```

Скрипт заодно готовит `Assets/web/my_name.png` для hero (обрезка и ресайз до 1500 px).

Раскладка: слева — Telegram и почта, справа — Instagram.
Все привязаны к верхнему краю и качаются при скролле (направление — наружу).
Ссылки берутся из `SITE.contacts` в `js/config.js`.

## Hero

Фон — видео `Assets/hero_background.mp4` (1920×1080, 8 с, ~7,7 МБ), автоплей без звука.
Имя — картинка `Assets/web/my_name.png` на светлой «бумажной» подложке: буквы чёрные,
поэтому под ними стоит светлый объект с рваными краями и тенью (`.hero__name` в `css/style.css`).

Заменить видео — положить файл с тем же именем или поправить `<source>` в `index.html`.
7,7 МБ для первого экрана многовато: лучше пережать до 3–6 МБ (H.264, 1080p, CRF 24–26,
`-movflags +faststart`), тогда старт будет быстрее.

## Тексты и язык

Все подписи — в `js/i18n.js` (ключи `ru` и `en`). Переключатель RU/EN в шапке
запоминает выбор в localStorage.

## Внешний вид

- Палитра, шрифты и отступы — переменные в начале `css/style.css` (`:root`).
- Карточки лент работ — квадрат; размер задаётся `--card-size` (по умолчанию 260 px).
  Фото заполняют квадрат через `object-fit: cover`; чтобы показывать кадр целиком —
  замените на `contain` у `.card img`.
- Готический акцидент сейчас — Cinzel. Замена шрифта: `--font-display`.
- Сетка: 4 скилл-секции, кейсы 2×2, схема процесса, услуги 3 колонки.
- Всё адаптируется под ширину между кадилами. Дизайн рассчитан на ширину от 1280 px;
  на меньших экранах появляется горизонтальная прокрутка (мобильной версии нет).

## Деплой на GitHub Pages

1. Создайте репозиторий и загрузите файлы в ветку `main`.
2. Settings → Pages → Build and deployment → Deploy from a branch.
3. Branch: `main`, папка `/ (root)`. Сохранить.
4. Через минуту сайт будет на `https://<username>.github.io/<repo>/`.

Домен можно подключить позже в том же разделе Pages.
